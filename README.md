Being open means:

- Open to your input and feature requests
- Open API

We listen to the needs of our users and implement requested features. You can also contribute a feature, and we will work with you to make sure it works for everyone.

## What is not in this repository

With a very heavy heart, in the summer of 2026 we stopped publishing our source code freely on GitHub.

The reason is that AI makes it possible to use open-source code as inspiration for proprietary code without respecting the original open-source license. In our opinion, this is not what open source is meant to enable.

We continue to support the open-source way of working with our clients:

- We implement users' feature requests for them.
- We share the code with them and collaborate with their developers when they want to work that way.
- Our team reviews and merges contributions and ensures their quality.

This is what we see as the third generation of open source: a professional company carries out most of the development, backs the product, provides support and updates, and offers hosting.

If you are interested in working this way with us, [please get in touch](https://www.translate5.net/en/contact/).
